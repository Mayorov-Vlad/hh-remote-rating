# Рейтинг удалённых профессий по счётчику «смотрят» (hh.ru)

**Дашборд:** https://mayorov-vlad.github.io/hh-remote-rating/ — снимок 28 октября 2026, 100 вакансий с наибольшим числом откликов (вся Россия, все форматы работы).

Метрика: счётчик «Сейчас эту вакансию смотрят N человек». hh.ru отдаёт его прямо в выдаче поиска (`online_users_count`). Это то же число, что `excludingCurrent` на странице вакансии, проверено 2026-10-07. Поэтому один запрос выдачи даёт счётчики сразу для 50 вакансий профессии.

Вместе со счётчиком из выдачи сохраняется всё, что может влиять на просмотры: тариф размещения (Премиум, Стандарт+, Стандарт, Зарплата.ру), платное продвижение, позиция в выдаче, дата публикации, зарплата (вилка, до или после налогов), опыт, занятость, график, часы, регион, число откликов, тест и сопроводительное при отклике, работодатель (рейтинг и отзывы, IT-аккредитация, HR-бренд, кадровое агентство, пометки антифрода), брендированное оформление, активность HR. Сырой объект вакансии хранится в `vacancy_raw`, чтобы позже разобрать любое поле без повторного сбора.

## Правила

- **Регион** — вся Россия (`search.area = 113`). Удалённая работа не привязана к городу; регион публикации — один из факторов.
- **Удалённая вакансия** — только с форматом «только удалённо» (`REMOTE`). Вакансии, где удалёнка — один из вариантов (офис/гибрид/удалённо) или есть разъезды, не считаются. Выборочная проверка текстов показала, что в смешанных вакансиях удалёнка часто частичная или с условиями.
- **Профессия в исследовании («может работать удалённо»)** — у неё не меньше 10 уникальных чисто удалённых вакансий (`curation.min_pure_remote`) и они составляют не меньше 2% всех её вакансий на hh во всех форматах (`curation.min_pure_share`). Второе условие отсекает профессии, где удалёнка — редкое исключение: врач, технолог, офис-менеджер, администратор.
- **Офисные и гибридные вакансии** собираются только по этим профессиям (`measure --full`): так их можно сравнить с удалёнкой той же профессии.
- **Выборка** — вся выдача hh по профессии (`analysis.sample_size = 2000`; больше 2000 на запрос hh не отдаёт — это касается только «Менеджера по продажам» и «Оператора колл-центра»). В дашборде фильтр «Глубина» сужает выборку до первых N вакансий выдачи.
- **Копии** — вакансии одного работодателя с одинаковым названием в одной профессии (часто одна вакансия опубликована в нескольких городах). В рейтинг идёт копия с самой высокой позицией в выдаче (`analysis.dedupe`). В Excel они лежат на листе «Копии (исключены)», в дашборде включаются переключателем.
- **Встроенная проверка.** Если на момент замера у профессии меньше 10 чисто удалённых вакансий, она уходит из рейтинга в лист «Проверка удалёнки». Вакансия без REMOTE (сбой фильтра hh) в рейтинг не попадает никогда.
- **«Что влияет на просмотры»** — эффект признака считается относительно той же профессии: во сколько раз среднее геометрическое `смотрят + 1` в группе выше, чем по всей профессии. По всем вакансиям эффект в среднем равен нулю, состав профессий в группе результат не искажает.

## Команды

```bash
pip install -r requirements.txt
python -m hhremote taxonomy                      # отрасли и профессии из справочника hh
python -m hhremote discover --target 1 --max-pages 1   # разведка: 1 страница на роль, сколько вакансий
python -m hhremote measure --all                 # замер удалёнки: все роли, вся выдача «удалённо»
python -m hhremote discover --any-format --target 1 --max-pages 1   # разведка без фильтра формата: сколько всего вакансий, по регионам
python -m hhremote curate --snapshot <id>        # отбор профессий по данным замера -> reports/professions_review.xlsx
python -m hhremote pulse --every 20 --until 2026-10-09T23:59   # пульс активности hh по времени суток; --report — кривая
python -m hhremote measure --full                # большой замер: все форматы по профессиям из отбора (~4700 запросов, ~2 ч)
python -m hhremote measure --control             # контрольный замер через 30–60 мин
python -m hhremote stability <id> <id контроля>  # устойчивость рейтинга между замерами
python -m hhremote analyze                       # рейтинги -> reports/rating_*.xlsx
python -m hhremote html                          # HTML с раскрытием отрасль → профессия → вакансии
python -m hhremote dashboard                     # интерактивный дашборд -> reports/dashboard_*.html
python -m hhremote export                        # вся база в CSV -> reports/csv/ (--raw: ещё сырые объекты hh)
python -m hhremote status                        # что в базе
```

Замер удалёнки по всей России — около 670 запросов, 20 минут. Большой замер (`--full`) — около 4700 запросов, 2 часа: hh отдаёт не больше 2000 вакансий на запрос, поэтому запросы по крупным профессиям дробятся по 19 крупнейшим регионам, а регион больше 2000 — ещё и по опыту.
Если сбор прерван (капча, сеть), продолжить: `python -m hhremote measure --full --resume <id снимка>` (или `measure --resume <id> --max-pages 40` для замера удалёнки).
Пауза между запросами меняется флагом `--delay 0.8,1.5`.
Снимки `--trial` и `--control` команды `analyze`, `html`, `dashboard` по умолчанию не берут, только через `--snapshot <id>`.

## CSV

- В дашборде кнопка «Скачать CSV» выгружает вакансии под текущие фильтры; без фильтров — вся база дашборда (36 столбцов).
- `python -m hhremote export` пишет в `reports/csv/` все таблицы базы и `base_s<id>.csv`: одна строка на вакансию в выдаче профессии со всеми полями и пометками «чисто удалённая», «копия», «в рейтинге».
- Формат под русский Excel: разделитель `;`, десятичная запятая, UTF-8 с BOM.

## Настройки — `config.toml`

- `search.area` — регион: 1 = Москва, 2 = Санкт-Петербург, 113 = вся Россия.
- `search.max_pages` — предел страниц выдачи на роль (40 = максимум hh).
- `analysis.sample_size` — размер выборки на профессию (2000 = вся выдача).
- `analysis.pure_remote_only` — `true` берёт только чисто удалённые вакансии.
- `curation.min_pure_remote` — порог включения профессии (10).
- `curation.min_pure_share` — минимальная доля чисто удалённых среди всех вакансий профессии (0.02).

## Ручной отбор — `curation.csv`

Разделитель `;`, кодировка UTF-8. Колонки: `profession_id;industry_id;included;reason`. Пустое поле означает, что остаётся автоматическое решение. `included = 0` исключает роль и из обхода `measure --all`. После правки запусти `curate` ещё раз.

## Данные — `data/hh.sqlite`

| Таблица | Что хранит |
|---|---|
| `industries` | отрасли |
| `professions` | профессии: основная отрасль, включена ли |
| `profession_industries` | все категории hh, в которые входит роль |
| `snapshots` | снимки: discovery, measure, control, trial, pulse |
| `search_results` | ответ выдачи по роли: сколько всего найдено вакансий |
| `search_queries` | отдельные запросы внутри профессии в большом замере (регион, опыт, формат) |
| `search_clusters` | счётчики фильтров hh по роли: форматы, регионы, опыт, занятость, график |
| `vacancies` | карточки вакансий со всеми признаками |
| `observations` | снимок × роль × вакансия: позиция в выдаче (внутри запроса `query`), «смотрят», отклики, активность HR |
| `vacancy_raw` | сырой объект вакансии из выдачи (zlib-JSON) |

Сравнивать профессии можно только внутри одного снимка.

## Ограничения

- Капчу скрипт не обходит. Если hh.ru её показал, сбор останавливается.
- Счётчик «смотрят» мгновенный: у отдельной вакансии шум большой, у медианы профессии — малый. Проверка — `stability`.
- Описание вакансии и ключевые навыки есть только на странице вакансии (1 запрос на вакансию, ~6 часов на всю базу) — в сбор не входят.
